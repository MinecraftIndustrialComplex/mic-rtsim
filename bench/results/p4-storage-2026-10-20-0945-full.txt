Notes:
- Single thread. No bevy Schedule, System or executor: QueryState cached and driven directly.
- Every bevy step calls World::increment_change_tick first, as a system run would; change ticks are written as bevy always does, except in the 'bypass' lines.
- Variants of one pattern and size are measured interleaved, run by run, after a calibration that doubles as warm-up.
- Every variant of every pattern was checked to end in the same state on a 20,000-row world before timing.
- Tagged rows (patterns d2, e): 1014 of 100000, 9887 of 1000000.
- A counting global allocator is installed for pattern g; every variant pays its atomic add per allocation.
- Slice loops (a, b, f and the e flag split) run in shared out-of-line kernels, so cols, bevy contig and bypass execute identical code.
- Built with loop headers aligned to 64 bytes (-C llvm-args=-align-loops=64, bench/p4-storage/.cargo/config.toml). Without it, identical loops ran up to 50% apart between builds that differed only in unrelated code.
