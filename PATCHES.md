# mic-rtsim patch ledger

Every mixin, every reach into another mod's or vanilla's internals, and every other mod's API the
rtsim depends on, with the mod and versions it was checked against, the member, and why (P7, taken as
recommended: a ledger plus contract tests). Written 2026-10-20 for the core bridge `mic_rtsim` and the
phase 1 plugins `mic_rtsim_ribbits` and `mic_rtsim_carryon` (`neoforge/`); the industry module (the
core's `industry` package) and the Create plugin `mic_rtsim_create` added the same night; the Ice and Fire
plugin `mic_rtsim_iceandfire` (phase 2's dragons, no mixin) added the same night too; the core's
vanilla herd adapter (package `herd`, docs/boundary.md §8.5) the same night, with row 21; the core's habitat
sampler (package `habitat`, docs/boundary.md §10) the night after, with no mixin; the industry plugins
(`mic_rtsim_oreexcavation`, `_dieselgenerators`, `_endertransmission`, `_powergrid`, `_destroy`, `_climate`,
`_radar`) and the threat sampler by overnight agent 14 (docs/overnight-choices-indplugins.md), with rows
22 to 24; the glass box's Create extraction (phase G1, docs/choices-glassbox-g1.md GB30 to GB59) with rows
30 to 33, read-only reflection (25 to 29 are left for concurrent branches); SEC-1's slice S1 (SECTIONS.md §2.8:
no chunk loads through Create's chain conveyors, rotation and network recount) with rows 50 to 59 (43 to 49 left
for concurrent branches).

**Contract tests.** Every mixin config is `defaultRequire 1`: a mixin whose target no longer matches
fails the launch, so booting a GameTest server is the first test of every row marked "mixin". The
"Checked by" column names the GameTest that exercises the behaviour (`./gametest.sh`; core tests run
with NeoForge alone, plugin tests with their mod's own jar).

**When a version moves** (a Minecraft, NeoForge, Ribbits, Carry On, Create or Ice and Fire update): re-read each row's member
in the new jar with `javap -p -c` (or the mapped source), then run `./gametest.sh`. Ranges below are
what was verified, not what is known to break.
