rtsim runs on TBSMP's own pack: all 11 dimensions, about 0.6 ms a tick, and three small fixes for Create addons MIC lacks

You asked: "can you not just grab their pack and add in the rtsim mod for it w/ compatability for any of the create mods they have that we don't". Yes, and it is done.

Merged on mic-rtsim main as 88b3e3b (docs/stress-tbsmp-results.md), 21 October 2026. The world and its jars stay on the laptop for private testing; no world files are on this page. The survey that picked this world is further down.

TBSMP Season 2's pack was rebuilt from the versions its world records, and the world boots on it with every dimension. mic-rtsim was then added and run beside the same world without it. rtsim logged no error or warning in 3 runs, and a profiled run puts it at about 0.57 ms a tick, mostly reading inventories. Three Create addons MIC lacks needed one small change each, with no new block, item or entity. The world loses one mod, Create Egg Production.

The pack: rebuilt at the world's versions, then moved to Create 6.0.10 for rtsim

  • 142 mods at the exact versions the save records: 119 from Modrinth, 8 from CurseForge and 15 that ship inside other jars, as a packwiz pack. On that pack (NeoForge 21.1.188, Create 6.0.6) the world boots clean.
  • rtsim targets Create 6.0.10, so the test instance moved to NeoForge 21.1.249 and Create 6.0.10, and 11 jars moved with it. A new link check read every jar for calls into parts of Create and NeoForge that are gone; each moved jar is the first version that passes it, not the newest.
  • What broke was the pack's, not rtsim's. Five Create addons called parts Create 6.0.7 removed: Garnished crashed the server on the first fan with a freezing recipe. Moonlight broke on the newer NeoForge. Two mods bind fixed ports, so a second server on the laptop failed; the test harness now gives each server its own port and ends one that hangs at stop.

What the world loses

  • Create Egg Production, which has no build for Create 6.0.7 and later. Its 40 egg collectors and 7 incubators load as air.
  • Supplementaries keeps a known GUI break on the newer Moonlight. Only a player opening one of its single-player GUI blocks, or a recipe display, reaches it; a server with nobody on never does. It stays at the world's version.

Each change is a tag or a model rule in the existing Create plugin. No new plugin, block, item or entity.

  • Not modelled: Slice and Dice's slicer (36 in the world, 5 in the adopted areas). Items under it pass through the model unprocessed, and what it makes reaches rtsim only through the catch-all node for machines rtsim does not model. It stays that way until a MIC pack carries it.
  • Needed nothing: Some Assembly Required and Create Food use Create's own recipe types; Create: Framed and Rechiseled: Create are decorative or too few to matter; Lootr's chests already count as storage.

The station gap. day_b's station sits in a chunk with no machine, so under DS-10 that chunk dropped out of the district, and rtsim stopped seeing the train that called there 12 times. It is being fixed in DS-10: a station joins the district next to it but never starts one, so a lone station on a line stays out.

For this run, Sophisticated Storage's controller, link and I/O blocks were added to DS-10's list of blocks that never start a district. The report recommends adding them for real when DS-10 lands.

Decided without asking: nothing here needs you, and each can be undone

  • Slice and Dice's slicer stays unmodelled until a MIC pack carries it.
  • mic-rtsim's Carry On plugin now accepts Carry On 2.2.2 and later (5059d6c; it required 2.2.6). TBSMP runs 2.2.2.11, which has the same pickup event, and the plugin ran on it with no error.
  • The test instance runs NeoForge 21.1.249 and Create 6.0.10; the packwiz pack keeps the world's own versions.
  • Create Egg Production stays out of the test instance, and Supplementaries stays with its GUI break.
  • alltheleaks 0.1.17 stands in for 0.1.16, which was never published.
  • The CoD mod's fixed port is not remapped: paired runs are symmetric, and the harness ends a server that hangs at stop.
  • Compat went into the existing plugin as tags and model rules, not a new plugin.
  • A second control and a profiled run were added because the first control ran under heavy load.

How TBSMP was found: thirteen worlds, five used, the rest too small or too lossy

TBSMP Season 2 (The Broken Script SMP) is public on archive.org with no login: an 8.67 GB zip that unpacks to a 13.5 GB world. It runs Minecraft 1.21.1 on NeoForge with Create 6.0.6, and 1,041 players joined it over its life. It is the only public world found that is both a multiplayer SMP and a Create 6 world, and it is far bigger than any other in chunks, track and Create machines. On MIC's own pack only its overworld and nether would load, since 9 of its 11 dimensions come from mods MIC lacks; that is why it ran on its own pack.
